# Hyrbart – första fungerande prototypen

Detta är en mobilförst Next.js-prototyp av Hyrbart baserad på det designsystem och den informationsarkitektur som tagits fram i chatten.

## Det som finns med
- Hem
- Produkter
- Produktsida för Kärcher SE 3 Compact
- Lång scrollbaserad användarguide med ankarnavigering
- Hyresvillkor som egen sida
- Liquid Glass-bottenmeny: Hem / Produkter / Hyresvillkor
- Kärcher som pilotprodukt med innehållsstruktur som senare kan flyttas till Sanity

## Kör lokalt
```bash
npm install
npm run dev
```
Öppna sedan http://localhost:3000

## Nästa steg
1. Lägg projektet i ett GitHub-repo.
2. Koppla repot till Vercel och skapa preview-deployment.
3. Byt statisk produktdata mot Sanity-schema och Sanity-klient.
4. Lägg in riktiga produktbilder och exakt Hygglo-länk.
5. Färdigställ hyresvillkor och integritets-/kamerainformation.
6. Koppla hyrbart.se när preview-versionen är godkänd.

## Viktigt om bildmaterial
Produktbilderna i denna version är kodgenererade placeholders. De ska bytas mot riktiga foton/produktbilder innan publicering.
